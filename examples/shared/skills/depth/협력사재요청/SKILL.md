# 협력사재요청: 서류가 빠진 협력사에 재요청 메일 초안을 쓴다

## 메일 설정
- 발신 계정은 support@example.com을 쓴다.
- 서명은 "고객지원팀 드림"으로 끝낸다.
- 제목 앞에 [문의번호]를 붙인다.
- 본문 첫 줄은 받는 사람 이름과 "안녕하세요"로 시작한다.
- 첨부 파일은 10MB를 넘기지 않는다.
- 발송은 사람이 확인한 뒤에만 한다.

## 절차
1. 검토필요목록에서 사유가 "서류 미비"인 협력사를 고른다.
2. 승인공급사목록.csv에서 담당자 이름을 찾는다.
3. 빠진 서류 이름을 넣어 재요청초안을 만든다.

## 판단기준
- 빠진 서류가 둘 이상이면 하나의 메일에 목록으로 적는다.
- 담당자 이름이 없으면 "담당자님"으로 쓴다.

## 산출물
재요청초안. 발송하지 않는다.
