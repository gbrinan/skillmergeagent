# 주간회의준비 통합 계약 (CONTRACT)

팀이 합의한 인터페이스 계약이다. 스킬 본문은 자유롭게 쓰되 아래 이름들은 문자열 그대로 지킨다.
고쳐야 할 이유가 생기면 스킬이 아니라 **이 파일을 먼저 고친다** (SSOT).

```contract
tables:
  회의록목록.csv: 파일명, 일자, 주제
  액션아이템.csv: 담당, 내용, 기한
  주간안건.csv: 안건, 출처, 우선순위

writers:
  액션아이템.csv: 액션아이템추출
  주간안건.csv: 안건정리

chain: 회의록요약 -> 액션아이템추출 -> 안건정리 -> 안건확정

payloads: 회의록, 회의요약, 액션아이템목록, 주간안건초안, 확정안건

threshold: (해당 없음)

halt_at: 안건확정
```

## 계약이 정하지 않는 것
- 스킬 본문의 서술 방식, 처리 로직의 세부, 예외 메시지 문구
