# homonym: 입출력과 표는 같은데 판단기준이 다른 두 스킬(동명이인)

`휴가신청검토`(팀원A)와 `휴가승인심사`(팀원B)는 둘 다 휴가신청을 받아 휴가판정을 내고, 같은 표(휴가신청.csv, 휴가판정.csv)를 읽고 쓴다. 이름만 보면 같은 일이다. 그런데 판단기준이 다르다. 한쪽은 잔여 일수와 겹침만 보고, 다른 쪽은 프로젝트 마감과 팀 최소 인원을 본다.

```bash
python3 check/similarity.py examples/homonym
```

를 돌리면 **동명이인 → 합치지 않음**으로 뜬다. 합치면 한쪽 팀의 규칙이 사라진다. `weave`가 갈림길(어느 팀의 신청인가)로 다룬다.

이 예시는 `similarity.py`의 "입출력·표가 같아도 본문 겹침이 낮으면 동명이인" 규칙에 근거를 대는 자료이기도 하다(`check/calibrate.py`).
