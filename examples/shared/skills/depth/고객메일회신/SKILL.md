# 고객메일회신: 고객 문의에 답장 초안을 쓴다

## 메일 설정
- 발신 계정은 support@example.com을 쓴다.
- 서명은 "고객지원팀 드림"으로 끝낸다.
- 제목 앞에 [문의번호]를 붙인다.
- 본문 첫 줄은 받는 사람 이름과 "안녕하세요"로 시작한다.
- 첨부 파일은 10MB를 넘기지 않는다.
- 발송은 사람이 확인한 뒤에만 한다.

## 절차
1. 문의목록.csv에서 미회신 문의를 고른다.
2. 문의 유형(배송·환불·기타)에 맞는 답변 틀을 고른다.
3. 회신초안을 만든다.

## 판단기준
- 환불 문의 → 주문일이 7일 이내면 승인 안내, 아니면 규정 안내.
- 배송 문의 → 송장번호가 있으면 조회 링크, 없으면 확인 중 안내.

## 산출물
회신초안. 발송하지 않는다.
