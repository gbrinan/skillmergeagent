# prose: `next`가 없고 순서가 본문에만 적힌 스킬 다섯 개

공개 스킬 692개 중 `next` 필드를 쓰는 것은 0개였다. 대신 본문이 "그다음 X로 넘긴다", "Y 스킬을 호출한다"처럼 서로를 부른다. 이 폴더는 그 모습을 흉내 낸 것이다. frontmatter에 `inputs`·`outputs`·`next`가 없다.

```bash
python3 check/flow.py examples/prose
```

를 돌리면 본문에서 이런 그림을 읽어낸다.

- 순서(추정): 견적요청접수 → 견적산출 → 견적검토
- 하위스킬(추정): 견적산출 → 단가표조회
- 불려도 폴더에 없는 스킬: 견적발송 (견적검토가 넘기는데 파일이 없다)
- 고아: 고객만족조사. 본문에 다른 스킬 이름이 나오지만 "~와 달리"라는 비교 나열이라 간선이 아니다
