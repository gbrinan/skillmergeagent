# shared: 다른 일을 하는데 같은 문단을 든 두 스킬

`고객메일회신`(고객 문의에 답장)과 `협력사재요청`(서류 미비 협력사에 재요청)은 입력·출력·표가 다르다. 그런데 "메일 설정" 여섯 줄이 글자까지 같다. 한 사람이 다른 사람 것을 복사했기 때문이다.

```bash
python3 check/similarity.py examples/shared
```

를 돌리면 **공통부분 → 참조 추출**로 뜬다. 합치지 않는다. 그 여섯 줄을 `shared/메일설정.md` 하나로 뽑고 두 스킬이 그 파일을 가리키면, 서명이나 발신 계정이 바뀔 때 한 곳만 고친다.
